LGPD – Lei Geral de Proteção de Dados

Última atualização: 15 de novembro de 2024

1. O que é a LGPD?

A Lei Geral de Proteção de Dados (Lei 13.709/2018) estabelece regras sobre coleta, armazenamento, tratamento e compartilhamento de dados pessoais. No Pet Shop Morada dos Pássaros, respeitamos rigorosamente essas diretrizes para garantir a sua privacidade e a segurança das suas informações.

2. Quais dados coletamos e por quê?

Coletamos apenas os dados estritamente necessários para a prestação dos nossos serviços, sempre com base em uma das hipóteses legais previstas na LGPD:

  • Identificação: nome, CPF, endereço, telefone, e-mail – para agendamentos, emissão de notas fiscais e comunicação.
  • Dados do pet: nome, raça, idade, histórico clínico – para atendimento veterinário e cuidados personalizados.
  • Dados financeiros: informações de pagamento (processadas por intermediários certificados, sem armazenamento interno).
  • Dados de navegação: cookies e IP – para melhorar sua experiência no site (veja nossa Política de Cookies).

3. Base legal para o tratamento

Utilizamos os dados pessoais com base nas seguintes hipóteses legais:

  • Consentimento: quando você nos fornece dados voluntariamente (ex.: formulários de contato, agendamentos).
  • Execução de contrato: para prestar os serviços contratados (banho, tosa, consultas, delivery).
  • Obrigação legal: para cumprir exigências fiscais, sanitárias e regulatórias.
  • Interesse legítimo: para melhorar nossos serviços e proteger a segurança de clientes e pets.

4. Compartilhamento de dados

Não vendemos seus dados. Compartilhamos apenas quando necessário para a execução dos serviços, com:

  • Parceiros veterinários (para exames, especialidades ou internações).
  • Plataformas de pagamento (processamento financeiro).
  • Autoridades judiciais/reguladoras quando exigido por lei.

Todos os parceiros são contratados com cláusulas de confidencialidade e proteção de dados.

5. Seus direitos como titular

A LGPD garante a você, titular dos dados, os seguintes direitos:

  • Confirmação da existência de tratamento.
  • Acesso aos seus dados pessoais.
  • Correção de dados incompletos, inexatos ou desatualizados.
  • Anonimização, bloqueio ou eliminação de dados desnecessários.
  • Portabilidade dos dados para outro fornecedor.
  • Eliminação dos dados tratados com base no consentimento.
  • Revogação do consentimento a qualquer momento.

Todos esses direitos podem ser exercidos de forma gratuita, mediante solicitação.

Adotamos medidas técnicas e organizacionais para proteger seus dados contra acessos não autorizados, perdas ou destruição. Os dados são mantidos pelo tempo necessário para cumprir as finalidades descritas ou por obrigação legal.
